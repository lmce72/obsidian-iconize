# Iconize 2.14.8：图标选择、嵌入与配置恢复

更新日期：2026-11-18（Asia/Shanghai）。本轮交付位于插件源码仓库，保留原有配置同步、逐条合并和历史保护实现。

## 使用变化

- 标题图标的点击、右键和键盘操作共用菜单：更改图标、更改颜色、获取 SVG 标签图标。
- 搜索框内提供清除按钮，右侧是圆形颜色控件。桌面 40×40px，窄屏或触摸设备 48×48px。选色立即影响下方图标预览，选中图标后一起保存；关闭选择器不保存预览颜色。规则选择器也接收所选颜色。
- 新增命令：将当前文档的所有 Iconize 标签嵌入实际图标、将整个 Vault 中带标签的文档嵌入实际图标、转换图标标签至 SVG 元素，以及配置诊断与恢复。
- 正文图标右键支持手动转换；编辑器使用标签偏移定位重复图标，阅读视图遇到同名标签时可按所在行选择。
- 自动转换默认关闭，开启后在停止输入 10 秒后运行，可设为 1–3600 秒。切换活动文档或卸载插件会取消待处理计时。

## 嵌入格式

默认格式是自包含 Base64 SVG 图片：`![LiHeart](data:image/svg+xml;base64,...)`。图标数据随 Markdown 文件携带，无需插件或外部附件；部分平台会限制 data URI，无法保证所有 Markdown 阅读器均支持。

设置还支持原始 `<svg>` 元素和 SVG 文件引用。转换器始终输出可复制的 SVG 元素。文件引用模式在 Vault 根目录的 `Iconize SVG/` 保存资源，相同内容复用、不同内容另存；分享时需要携带资源文件。

转换只处理正文，保留 YAML、围栏代码、行内代码、HTML 代码、链接目标和转义标签。找不到的图标保持原样。打开的文档通过单次 Editor transaction 修改，可以撤销；后台文档使用 Vault.process，并检查解析期间文档是否改变。

## 配置恢复

设置页和命令面板都能打开“配置诊断与恢复”。显示实际配置路径、读取状态、非法设置或记录的具体原因，以及最近保存错误。损坏配置仍保持禁止保存，避免默认值覆盖原文件。

支持修复后的重新读取，以及选择 `.bak` 或历史快照恢复。恢复前保全内存状态和当前文件原始字节；提交时检查文件是否被同步客户端改变。恢复过程中暂停后台保存和刷新。恢复后建议重新加载插件，使图标包路径等设置完整生效。

## 加载与检索

- 搜索、输入建议只生成有限结果，扫描按约 8ms 分片让出主线程；新输入取消旧扫描，精确名称优先。
- 不再为每次搜索复制整个图标库；设置页读取数量使用 pack.size，避免创建完整元数据数组。
- 图标包和解析器的启动登记分片执行；预览继续使用有上限、不落盘的缓存。
- ZIP/ZIP64 中央目录每次打开只解析一次，后续以偏移直接读取目标条目，不再为每个预览重扫整个压缩包。关闭选择器仍释放归档字节。
- 修复大型数组展开导致的参数数量溢出风险。

- 测试应用：Obsidian 1.15.0，Linux。
- 已验证 Base64 阅读视图显示、SVG 转换器、自动转换、撤销、重复标签右键定位、后台批量转换、标题菜单与颜色、配置故障提示、备份恢复和恢复后的插件重载。
- 桌面圆形控件实测 40×40px；360px 触摸视口中为 48×48px，清除按钮触摸区域 48×48px，搜索框、颜色控件及三列图标网格无横向溢出。此项为桌面模拟，尚未进行移动端真机测试。

- 单元测试覆盖 300,000 条检索、事件循环让出、ZIP/ZIP64、UTF-8 文件名、转换保护、10 秒防抖、过期编辑、配置损坏与恢复竞争。
- 233 项测试通过，13 项沿用原项目跳过状态；类型检查、变更源码 ESLint（零警告）、全 src ESLint 错误检查和生产构建通过。

最低 Obsidian 版本调整为 1.7.2，匹配当前使用的适配器原子处理 API；没有在旧版本应用或移动端真机上验证。未进行社区发布或额外的 source review 服务扫描。
